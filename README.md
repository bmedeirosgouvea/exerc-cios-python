# 📘 Exercícios de Python no Google Colab

Este repositório contém uma coleção de exercícios realizados em Python no ambiente Google Colab. Os exercícios abrangem desde fundamentos da linguagem até manipulação de listas, strings, estruturas condicionais, loops e funções matemáticas.

---

## 🧠 Conteúdo Abordado

- Operações matemáticas básicas
- Manipulação de strings
- Estruturas condicionais (`if`, `else`)
- Loops (`for`, `while`)
- Listas, dicionários, tuplas
- Comprehensions
- Funções matemáticas com `math`, `random`, `numpy`
- Leitura de dados com `input()`
- Simulações e sorteios
- Estruturação lógica de problemas

---

## 📂 Estrutura

```
exercicios_python_colab/
├── exercicios_colab.py   # Código com todos os exercícios resolvidos
└── README.md             # Documentação do projeto
```

---

## 🧪 Como executar

1. Abra o arquivo `exercicios_colab.py` em qualquer editor de código Python (como VSCode ou Jupyter)
2. Execute os blocos interativamente para treinar cada tipo de exercício
